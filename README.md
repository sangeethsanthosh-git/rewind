## 📻 Overview

**Rewind** transforms your smartphone into an authentic, vintage portable cassette Walkman. It is designed around the tactile joy of physical media: realistic mechanical button clacks, cassette loading and ejection, rotating spools, motor startup sound effects, and an interactive cassette case that unlocks when you select a song.

Built entirely with **Flutter**, **Riverpod**, and **Just Audio**, Rewind is 100% offline-first with zero tracking, zero telemetry, and maximum audio fidelity.

---

## ✨ Features

- **📼 Signature Walkman Experience**
  - Realistic mechanical sound design (play clacks, cassette load/eject, motor hum).
  - Realistic cassette case opening animation with J-card track info and tape label.
  - Rotating cassette reels with dynamic tape spooling during playback.
  - Tactile physical button animations with responsive haptic feedback.

- **🎛️ Hi-Fi Local Audio Engine**
  - Hardware-accelerated local audio decoding via ExoPlayer.
  - Native lossless playback support: **FLAC, MP3, WAV, AAC, ALAC, OGG, Opus**.
  - Gapless playback and sleep timer support.

- **🎨 Deep Customization & Retro Aesthetics**
  - **Custom Image Wallpaper**: Upload any image as background with full responsive controls.
  - **Dynamic Song Canvas**: Displays track banner art seamlessly across the app background.
  - **Background Blur Adjuster**: Real-time slider from 0 px (ultra-crisp) to 25 px.
  - **Custom Accent & Button Colors**: Switch between Neon Orange, Cyber Lime, Electric Cyan, Analog Amber, Vinyl Red, Synth Purple, and Studio White.

- **📁 Europe Deluxe Disc Navigation**
  - Vinyl-inspired turntable disc interface for browsing local folders and custom cassettes.

- **🔒 100% Offline & Private**
  - All metadata, history, and settings stay strictly on your device.
  - Zero cloud dependencies, zero analytics.

## 🛠️ Build from Source

```bash

# Fetch dependencies
flutter pub get

# Run test suite
flutter test

# Build release APK
flutter build apk --release --split-per-abi
```
